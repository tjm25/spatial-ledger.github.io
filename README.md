# 📦 Spatial Ledger – April 2025 Prototype (Archived)

This is an archived version of the early Spatial Ledger prototype.

It was built in early 2025 as a proof-of-concept for AI-assisted Local Plan tracking, presumption trigger analysis, and planning system audit logic.

Since then, more up-to-date work (e.g. Savills, DLUHC) has emerged. This version may contain outdated or incomplete classifications, and is no longer actively maintained.

It remains preserved here for transparency, citation, and historical context.

**Built entirely without institutional support, as an experiment in public planning reasoning infrastructure.**

For newer planning work, see: [https://tim-mayoh.bearblog.dev/](https://tim-mayoh.bearblog.dev/)
